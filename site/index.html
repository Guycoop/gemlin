What it does

skills

Knows your laptop

Comes with skills for your Downloads, big files and folders, busy apps, battery, memory, duplicates and unsaved git work. It sees names, sizes and dates, never what's inside your files.

desktop pet

Lives on your screen

Walks back and forth, turns to face you when it talks, and answers in speech bubbles. Chat in its little window, or drag it somewhere else.

learn_skill

Teaches itself tricks

Ask for something it can't do yet and it writes a new Python tool. It shows you the code first, and nothing runs until you say yes.

safe by default

You're in charge

Its tools only look; they never change anything. Its one action moves a file into a review folder, never deletes, and always asks first.

Ask it anything about your laptop

Type into Gemlin's little chat window and it answers in a speech bubble. When it uses a tool it tells you, and anything that changes your machine waits for your yes.

Install it

All you need is a Google account. Open a terminal, paste one line, and Gemlin takes it from there.

  1. Paste this into a terminal

    curl -LsSf https://gemlin.dev/install.sh | sh
    powershell -ExecutionPolicy ByPass -c "irm https://gemlin.dev/install.ps1 | iex"

    On a Mac, open Terminal (press ⌘ Space and type Terminal). It installs Gemlin with its own Python, so nothing else on your computer changes. Read the script.

    Open PowerShell from the Start menu. It installs Gemlin with its own Python, so nothing else on your computer changes. Read the script.

  2. Say hi

    Gemlin wakes up on your desktop with its chat window open, and you can close the terminal. The first time, it helps you get a free Google API key right there: click Get a free key, then paste the key into its chat box. The installer also adds the Gemlin app and asks whether Gemlin should wake up whenever you log in. No Google account, or want everything offline? With LM Studio or Ollama and a Gemma model, type local instead of a key.

  3. Make it yours

    Click Customize me under Gemlin's chat box (or open the creator), pick a name, personality, hat and colors, then paste the code back into its chat.

Want to change Gemlin's code? Install it from source instead

You'll need Python 3.10 or newer and git.

git clone https://github.com/alexinslc/gemlin cd gemlin python3 -m venv .venv source .venv/bin/activate pip install -e . gemlin start
git clone https://github.com/alexinslc/gemlin cd gemlin python -m venv .venv .venv\Scripts\activate pip install -e . gemlin start

Edits take effect after gemlin restart. In a new terminal, run the activate line first.

No terminal needed

the app

Open Gemlin like any app

Find it in Launchpad, Spotlight or Applications on a Mac, or in the Start menu on Windows. Opening it wakes Gemlin up, or brings up its chat if it's already awake.

menu bar & tray

Always one click away

Gemlin stays out of your Dock and lives in the Mac menu bar (or the Windows system tray), with its whole menu: chat, customize, walk around or stay put, wake up at login, updates.

right-click

Or just right-click Gemlin

The same menu, right on the creature. Go to sleep puts Gemlin away until you open the app again.

The gemlin command

Everything is also a command, for people who like terminals.

gemlin startWake Gemlin up on your desktop
gemlin stopPut it to sleep (so does right-click → Go to sleep)
gemlin restartStop, then start, after you change its skills or code
gemlin statusIs it awake? Is your key saved?
gemlin autostart onWake up whenever you log in (off turns it off)
gemlin setupCheck everything and save your API key from the terminal
gemlin look CODEUse a look from the creator (or just paste the code into Gemlin's chat)
gemlin skillsList its skills; skills add FILE adds one someone shared
gemlin develop IDEABuild a new skill with Gemma's help
gemlin logsSee what Gemlin has been doing
gemlin model localThink with Gemma on your own computer (LM Studio or Ollama): no key, nothing leaves your laptop
gemlin updateUpdate to the newest version (or Check for updates… in its menu)
gemlin uninstallPut it to sleep and remove its app and login item

In Gemlin's chat window, type /help for shortcuts like /develop and /skills.

Make it do more

Teach it new tricks, with Gemma's help

Every skill is one small Python file. Describe the one you want and Gemma writes it. Gemlin checks it against the rules, you try it, ask for changes in plain words, and save it.

In a hurry? Type /develop and your idea in Gemlin's chat window. There are finished examples to read and try, too.
